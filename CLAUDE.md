## Constitution (Immutable Principles)

1. **Честная витрина** — на сайте только факты из источников; никаких выдуманных клиентов, внедрений, цифр и «уже работает»; запрещённые тезисы брифа §4.3 не публикуются; мокапы — только с демо-данными.
2. **Продукт — это файл** — новый продукт или страница добавляется контентом по схеме, мокапом и пунктом карты по runbook, без правок каркаса; новый тип секции (`view`) — осознанная правка каркаса, новый продукт и страница — нет; ручные списки навигации, карты и sitemap запрещены — всё строится из коллекций.
3. **Бренд через токены** — любой цвет, шрифт, размер, отступ, радиус и движение берутся только из слоя темы; якоря бренда (имя и нейминг Belka SCM, знак без перерисовки и перекраски, рыжий `#C4552A`, спокойный инженерный тон) неизменны, остальное свободно ради лучшего результата; русская редакция имени — только «Белка УЦП», одиночное «Белка» и «Белка SCM» как марка не используются; латинское имя продукта в тексте идёт с русским пояснением («Belka WMS — система управления складом»).
4. **Статика без ПДн** — никакого бэкенда, форм и сбора персональных данных; единственные cookie — Яндекс.Метрика после согласия и только при включённом флаге юрлица.
5. **Русский голос Belka** — весь текст только на русском по правилам голоса (спокойно, точно, «вы» со строчной, без восклицаний, ёлочки, тире с пробелами, тонкие пробелы в разрядах); каждый текст проходит цикл Claude → Codex → владелец, публикуется только утверждённое; видимый текст живёт в контенте (`src/content/`), в шаблонах — только служебные строки каркаса, и они проходят тот же цикл.
6. **Быстро и доступно** — Lighthouse ≥ 95 (perf/a11y/SEO/best practices) на мобайле и десктопе, адаптив от 360px, минимум клиентского JS, хостинг в РФ; гейты — в CI, а не на глаз.
7. **Каждый эпик — в прод** — эпик завершается публикацией на belkascm.ru через CI по коммиту с предварительным стейджингом; незаконченное не показывается, ссылки ведут только на существующие страницы.
8. **Гейт не отключают, его чинят** — любой гейт (`gates.yml` в CI и локальный гейт документов) нельзя ослабить, пропустить или сделать необязательным ради выкладки; гейт проверяет ровно заявленное (порог, агрегация, охват), и новый гейт приходит с пробой на пограничный случай; падение гейта — дефект, который разбирается через `/my-change`.
9. **Прод повторяет стейджинг** — в прод выкладывается только коммит, уже выложенный на стейджинг, пересобранный с теми же гейтами и тем же деплой-контуром, иначе промоушн отклоняется; ручные правки на сервере мимо git запрещены, конфигурация сервера живёт в `infra/`.
10. **Закоммичено — значит опубликовано** — всё, что попадает в репозиторий кода и его историю (файлы, сообщения и авторство коммитов, artifacts CI), публично: там только код, утверждённые тексты и `infra/` без секретов; документы, черновики, секреты, IP сервера, личная почта и сведения об основателях, клиентах и соседях по серверу — только в приватном контуре; авторство коммитов — только noreply.
